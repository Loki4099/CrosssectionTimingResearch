# G33 运行前实现澄清：月频 EWMA 起点

记录日期：2026-08-15
状态：**在任何 G33 结果或正式 bundle 产生前冻结。**

本记录不修改 [G33 冻结设计](./design.md) 的模型、参数、假设、评价门槛或输出契约，只澄清权威月频调仓日历与 EWMA 正方差初始化同时成立时的确定性边界处理。

## 边界事实

- 风险历史起点固定为 2014-06-30。
- 2014-06-30 是月末信号收盘，按冻结的 `signal close -> next XNYS open` 规则，若从该日现金启动，月频首次执行是 2014-07-01，因而 2014-06-30 的裸账簿收益会被机械写成 0。
- 冻结设计同时要求 `v(t0)=r(t0)^2`，并要求递推方差严格为正；因此不能沿用 G32 的月频首日零现金补点，也不能加入 epsilon、方差下限、默认满仓或跳过首日。

## 冻结处理

1. 周频不需要特殊处理：仍从 2014-06-30 的正常计划执行开始，随后只使用 2014-06-30 起的裸账簿收益。
2. 月频只为建立 2014-06-30 当日的真实存量持仓，从权威日历自动取该日前最近一次计划执行：2014-05-30 收盘信号、2014-06-02 开盘执行。
3. 2014-06-02 至 2014-06-27 的收益、方差或预测值均不进入 EWMA、分位数、状态或任何绩效指标；它们只使月频账簿在 2014-06-30 开盘前具有按冻结规则自然形成的持仓。
4. EWMA 输入严格切片为 2014-06-30 至 2026-06-30。两种频率都必须满足首值有限、严格大于 -100%、绝对值非零，且 `v(t0)=r(t0)^2>0`。
5. 该处理由冻结 XNYS 调仓日历唯一决定，不增加候选模型、参数、阈值或研究者选择轴；不得根据 G33 结果修改。

## 运行门禁

- 每条 36 核心路径的 EWMA 输入必须恰有 3,018 个连续权威交易日。
- 任何 2014-06-30 之前的收益不得出现在持久化 forecast regime 或 EWMA 递推输入中。
- 直接递推和 pandas `ewm(alpha=0.06, adjust=False)` 必须逐位一致；首个正式信号必须具有 756 个严格滞后的正预测波动率。
- 本记录的 SHA256 必须写入 G33 manifest provenance；G33 设计文件不得修改。
