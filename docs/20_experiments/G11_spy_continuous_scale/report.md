# G11：SPY 历史波动率连续 15% 目标缩放——结果报告

状态：**已完成；运行、因果性与会计审计有效，但预注册 long-only H1 明确失败。** 本报告只对应冻结数据 v3 与不可变运行 `g11-frozen-v3-v1`。G00 是唯一正式对照；G31 只在 G11 完成并通过验收后进入动作层解释，不是运行输入，也不是正式 reference。

## 一句话结论

连续 15% 目标缩放把 long-only 的最大回撤在 18/18 个主场景中压低，但 CAGR 与 T-bill 超额 Sharpe 也在 18/18 个场景下降，Sharpe 与 MDD 同时改善为 **0/18**，预注册 H1 因而失败。Long-short/WML 则在 18/18 个主场景、乃至全部 216/216 个成本×借券压力场景中同时改善 Sharpe 与 MDD，机制非常稳定；但主场景绝对 CAGR/Sharpe 仅为 4.77%/0.194，仍是弱的机制诊断。事后动作层比较中，G11 相对 G31 的 LO CAGR/Sharpe/MDD 更差，LS 则更好；这不能改写正式 G11-G00 判定。18 个 LO 路径的数值部署联合通过为 **0/18**，且 `formal_run_eligible=false`。

## 判定与下一步

1. G11 long-only 记为“回撤 18/18 改善，但 CAGR/Sharpe 18/18 下降，H1 失败”。连续缩放把 2018Q4、COVID 下跌和 2022 左尾压低，却在 Q1–Q3 也长期降仓，并在 COVID 反弹付出巨大 winner-long 机会成本。
2. G11 long-short 记为“机制稳健、绝对质量弱”：主场景和 216 个压力场景全部同时改善 Sharpe/MDD，主要来自减少 loser-short 左尾与反弹损失；绝对 Sharpe、换手、借券和容量限制仍禁止策略化表述。
3. G11 相对 G31 的 LO 更低风险但经济结果更差，不能称连续动作优于尾部动作；LS 的动作层改善只是 completed 后的描述性局部证据。正式 reference 始终只有 G00。
4. 18 个 LO 数值部署联合通过为 0，数据治理又永久保留 `formal_run_eligible=false`。15% 只是 SPY 风险源的目标尺度，不是动量组合实现波动率保证。
