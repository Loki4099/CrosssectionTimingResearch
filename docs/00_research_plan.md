## 1. 研究目标

本项目以美国股票为研究对象，从最基础的动量与反转效应出发，逐步构建并评价：

1. 基于 S&P 500 历史时点成分股的横截面选股策略；
2. 以历史波动率约束动量风险的择时或横截面策略；
3. 在不同市场状态下切换动量与反转信号的策略；
4. 预测动量策略自身未来波动率，并据此控制组合风险的策略。

第一轮的任务不是寻找最优参数，而是建立一个规则确定、无模型、可审计、可复现的动量基线。后续每一批实验只增加一种主要机制，以便辨认收益或风险改善究竟来自哪里。

## 2. 已冻结的共同口径

| 项目 | 决定 |
|---|---|
| 市场与股票池 | 历史时点（PIT）S&P 500 成分股；第一阶段不加市值或流动性过滤 |
| PIT 的职责 | 确定每个信号日当时有资格参选的股票，解决幸存者偏差 |
| 主基准 | S&P 500 Total Return；1993 年以后同时报告可投资基准 SPY 总回报 |
| 价格口径 | 用户口径的后复权数据；代码中统一称“总回报复权”价格，避免复权术语歧义 |
| 组合方向 | long-only 为主；long-short/WML 仅作因子诊断或后续扩展 |
| 组合权重 | 每个调仓点恢复等权；继续持有的股票也重新等权 |
| 调仓频率 | 周频和月频都研究 |
| 周频时点 | 每周最后一个交易日收盘后计算信号，下一交易日开盘执行 |
| 月频时点 | 每月最后一个交易日收盘后计算信号，下一交易日开盘执行 |
| 持仓宽度 | 第一轮 Top 10、Top 20、Top 50；Top 5 作为单独的集中度探索，不混入主基线 |
| 杠杆 | 第一轮不加杠杆；后续可用最高 1.5 倍作为独立对照，不能与无杠杆结果混报 |
| 防御资产 | 后续择时实验以 T-bill/无风险收益为主；可用 BIL、SGOV 做可投资性对照 |
| 模型训练 | 第一轮没有模型训练；未来若有模型，指标和模型都只允许使用当时可得数据滚动计算/训练 |
| 样本切分 | 不设置固定训练集、验证集和测试集；采用逐期 walk-forward，限制预先登记的参数组合数量 |
| 失败实验 | 不删除、不隐藏；与成功实验使用同一台账和输出标准 |

等权恢复会在已入选股票内部形成“减持相对上涨者、补足相对下跌者”的隐含反向再平衡。它属于组合构建和集中度控制，不应被误称为一个独立的反转因子。

## 3. 分批实验路线

### 批次 0：数据与回测基础设施

- 建立可替换的数据 Provider 接口；
- 接入 `yfinance + 外部 PIT 成分文件` 的原型数据路径；
- 预留 Norgate 正式数据 Provider；
- 生成统一的总回报复权价格、历史成分和基准数据；
- 完成日历、信号、持仓、换手、成本、净值和绩效模块；
- 建立防前视和数据覆盖测试。

### 批次 1：无模型动量基线

- 3 个动量定义；
- 3 个持仓宽度；
- 2 个调仓频率；
- 共 18 条主交易路径；
- 等权、long-only、满仓、不加杠杆；
- 成本率只是同一交易路径的报告情景，不增加策略数量。

详见 [第一轮基线规格](./01_round1_baseline_spec.md)。

### 批次 1E：集中度与因子诊断

在主基线完成且不改变其结论后，单独登记：

- Top 5 集中组合；
- WML/long-short 因子组合；
- 个股、Top 1/Top 3、行业贡献集中度；
- 剔除最大贡献股票或行业后的归因敏感性。

Top 5 的目的，是检验近年美国市场的巨头和行业集中现象是否增强了表面动量，而不是事后向主网格补入一个赢家参数。

### 批次 2：历史波动率择时

保持横截面动量排序不变，使用历史波动率控制风险资产仓位，其余配置 T-bill/无风险资产。首先比较无杠杆版本；最高 1.5 倍杠杆仅作为独立对照。

需要预先登记的设计项包括：波动率估计窗口、目标波动率、仓位上下限、调仓频率和防御资产。不得根据完整历史表现回填最优阈值。

### 批次 3：历史波动率参与横截面排序

历史波动率不再控制总仓位，而是约束或调整个股动量得分，例如风险调整动量、双重排序或波动率过滤。该批次仍然输出 Top K 等权组合，以分离“选股信号变化”和“风险预算变化”。

### 批次 4：市场状态下的动量—反转切换

使用只依赖当时信息的波动率状态规则进行 market regime 判别：常态使用动量排序，高波动或阈值突破状态切换为反转排序。阈值、持续期、滞后和退出规则必须事前写入实验配置。

### 批次 5：预测动量策略自身的未来波动率

预测对象是动量因子或动量组合未来波动率，而非仅预测市场波动率；根据预测值控制风险仓位。模型只在滚动窗口内训练，不设置单独验证集；每个窗口和超参数组合均作为一个独立、预先登记的实验。

## 4. 研究纪律与过拟合控制

不划分固定样本并不等于不存在策略选择偏差。每条路径可以在交易时点上严格 walk-forward，但研究者事后从大量历史路径中挑冠军，仍然利用了完整历史信息。因此采用以下纪律：

1. 每一批实验在运行前登记假设、参数网格和组合数量；
2. 第一轮只做 18 条主路径，不加入权重、缓冲带、杠杆或额外过滤器的笛卡尔积；
3. 数据清洗规则、交易成本和基准不能根据结果临时改变；
4. 所有有效、失败、无效和报错实验均保留；
5. 不按单一最高 Sharpe 选冠军，优先考察机制一致性和相邻参数的稳定平台；
6. 后续候选数量较多时，报告针对多重检验的 Reality Check/SPA 或 Deflated Sharpe 等统计诊断；
7. 研究规则冻结后的 paper/live forward 记录，作为真正未被研究选择污染的证据。

建议研究预算：单个主要机制族原则上不超过 18 条主路径；累计候选数量由实验台账持续记录。该预算是研究治理约束，不代表低于该数量就自动免于过拟合。

## 5. 评价标准

所有策略同时报告 gross 和 net 结果，并与相同起止日期、相同日历的基准比较。

核心指标至少包括：

- CAGR 与累计总回报；
- 年化波动率和 Sharpe；
- 最大回撤、回撤持续期和 Calmar；
- 相对 SPXTR/SPY 的超额收益、beta、tracking error 和 information ratio；
- 年度、滚动期和市场阶段表现；
- 双边换手与交易成本拖累；
- 个股、行业和时期收益贡献集中度。

当前研究合格参考线为：

- 净值口径 CAGR 高于同期 SPY 总回报 CAGR；
- Sharpe 大于 1；
- 最大回撤小于 25%。

这些是策略评估门槛，不是删除结果的筛选器。未达标路径仍须分析它失败于收益不足、成本、回撤、集中风险还是状态依赖。

## 6. 数据源路线与理由

### 原型阶段

使用 `yfinance + 外部历史成分文件`：成本低、开发快，适合先验证接口、时点逻辑和 18 条基线路径。原始下载必须版本化保存，不能每次运行覆盖旧数据。

`yfinance` 的主要局限不是“总回报复权一定错误”，而是它不直接提供完整的历史 S&P 500 成分体系、永久证券标识和正式的数据版本承诺。历史 ticker 数据缺失时，不能把该股票静默从候选池删除。

### 数据完善阶段

历史时点成分名单与价格数据分开处理。当前公开历史成分表继续作为股票池输入，并抽样核对成分变更；不因价格 Provider 不提供指数成员而否决该路径。

价格层优先采用低成本混合路线：Yahoo 覆盖正常代码，Tiingo 免费 EOD 补充 Yahoo 缺失、退市或异常代码，并建立显式 ticker 改名与并购退出事件表。若免费覆盖仍不足，再考虑一个月低价 Provider 做交叉验证。Norgate/CRSP 降为机构级复核或未来扩展选项，不是第一轮必须采购的数据源。

Provider 接口必须使数据源替换不改变策略模块。原型结果和正式数据结果分别登记，不能混合为同一数据版本。

## 7. 第一轮之外暂不优化的事项

以下设计全部延后并单独立项，不能在第一轮基线中隐式加入：

- Top 5；
- 市值或流动性过滤；
- 缓冲排名、最短持有期或减少换手规则；
- 波动率缩放、T-bill 切换和杠杆；
- 行业中性、单股/行业上限；
- 按市值、波动率或信号强度加权；
- 机器学习、动态参数选择；
- 盘中成交优化或更复杂的滑点模型。

## 8. 变更控制

本计划是后续上下文压缩时的事实来源。修改已冻结规则时必须：

1. 在实验台账中说明原因；
2. 更新受影响文档的版本和日期；
3. 已生成的实验不追溯覆盖；
4. 规则变化后创建新的实验 ID 或批次。
