# 研究主线

本项目现在按研究问题分成两条主线。历史设计、代码、结果和图表仍保留在原路径；本目录只提供稳定导航，不改变任何既有实验结论。

| 主线 | 研究问题 | 当前状态 | 入口 |
|---|---|---|---|
| 系统性 long-only 横截面 Alpha | 在历史时点 S&P 500 成分股中，哪些市场与基本面信号能稳定改善 Top-K 选股？ | **当前主线**；XA01与XA02已完成，XA03滚动聚合模型计划已冻结并授权、尚未执行 | [横截面 Alpha](./cross_sectional_alpha.md) |
| 防御择时与仓位控制 | 市场级风险信号能否降低裸横截面策略的尾部风险，并保留足够收益？ | **已完成的研究档案**；Round 1–10 已闭合，P00 在开发期通过、机械锁箱失败 | [防御择时](./defensive_timing.md) |

两条主线共享同一套历史时点股票池、证券身份、公司行动、交易日历、回测会计和审计约束。共同入口见[数据层](../10_data/README.md)、[实验档案](../20_experiments/README.md)、[参考资料](../30_references/README.md)和[图表索引](../figures/README.md)。
